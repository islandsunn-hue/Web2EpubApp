# Web2Epub
*This readme was written by Gemini and human reviewed.*

Web2Epub is a versatile Android application designed to bridge the gap between live web content and offline accessibility. It allows users to browse the web, open various archive formats, and convert content into high-quality offline documents.

## 🚀 Features

### 🌐 Web Page Conversion
Convert any live or archived web page into your preferred format:
- **EPUB**: Perfect for e-readers and mobile devices.
- **PDF**: Ideal for printing and professional sharing.
- **MHTML**: Save a complete snapshot of a web page in a single file.
- **HTML**: Standard web format for easy viewing.

### 📦 Archive Support
PowerUser1 goes beyond live browsing by supporting major offline formats:
- **ZIM**: Full support for Kiwix ZIM archives. Browse and search offline versions of Wikipedia, Stack Overflow, and more.
- **MHTML / MHT**: Open existing web archives directly.
- **HTML**: Load local HTML files for conversion or viewing.

### 🛠️ Advanced Tools
- **ZIM Search & Random**: Quickly find information within massive ZIM archives or discover something new with the "Random Article" feature.
- **Text-Only Mode**: Clean up cluttered web pages for a distraction-free reading and conversion experience.
- **Integrated Browser**: A powerful WebView-based browser that handles both live URLs and local/archive resources seamlessly.

## 🛠️ Tech Stack
- **Language**: Kotlin
- **UI Framework**: Android XML / View System (Migrating towards modern components)
- **Core Libraries**:
    - `libzim`: For efficient ZIM archive handling.
    - `WebView`: For high-fidelity web rendering.
    - `Jetpack Components`: For navigation and lifecycle management.

## 📖 How to Use
1. **Browse/Open**: Enter a live URL or use the navigation drawer to open a ZIM, MHTML, or HTML file.
2. **Clean (Optional)**: Enable "Text-Only Mode" to strip away ads and navigation for a cleaner export.
3. **Export**: Use the "Save" options in the menu to export the current view to EPUB, PDF, or MHTML.
